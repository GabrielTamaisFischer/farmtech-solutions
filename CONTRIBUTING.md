# Colaboração

1. Aceite o convite do repositório privado.
2. Clone o repositório e crie uma branch descritiva, por exemplo `git switch -c correcao/area`.
3. Faça alterações pequenas e confira o funcionamento.
4. Faça commit e envie sua branch ao GitHub.
5. Abra um pull request e solicite revisão a outro integrante antes de integrar à main.

Cada integrante deve usar a própria conta para registrar sua contribuição. Não compartilhar credenciais.
