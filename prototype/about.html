Sobre o projeto

O protótipo conecta a entrada de dados em Python, as estatísticas no R e uma visão visual para leitura dos resultados.

FarmTech Solutions

Objetivo

A aplicação apoia o planejamento de duas culturas agrícolas, calculando a área a partir da figura geométrica do terreno e estimando o volume de insumos para o manejo.

Os registros são organizados em vetores no Python. O fluxo permite inserir, listar, atualizar, excluir e exportar os dados para continuar a análise no R.

Fluxo dos dados

Python→CSV→R · média e desvio→Dashboard

A página de Dados concentra a operação do protótipo e a página de Análises apresenta os cálculos estatísticos.
