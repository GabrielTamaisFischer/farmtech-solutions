Análises estatísticas

Média, mediana, desvio padrão e amplitude calculados sobre os vetores exportados pelo programa Python e processados no R.

Python + R

Integração meteorológica

O script meteorologia.R consulta a API pública Open-Meteo em tempo de execução e exibe os dados no terminal.

API ao vivo
jsonlite::fromJSON() → temperatura, umidade, precipitação e vento

A mesma consulta é usada pelo cartão de clima do dashboard. O endpoint público não exige chave de API.
